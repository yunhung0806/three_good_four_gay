# 微光咖啡館 LUMINA CAFÉ

七天的小鎮生活模擬 RPG。以俯視像素地圖探索街道，進入咖啡館、學校、麵包店、雜貨店、公園與三位居民的人生記憶；經營咖啡館、自由對話，觀察善意如何在居民間流動。

## 啟動

Windows 可直接雙擊 `start-game.cmd`，或在專案資料夾的命令提示字元輸入：

```cmd
start-game.cmd
```

啟動器優先使用 Python 3.10 以上；若找不到 Python，則使用系統 Node.js 20 以上。無需安裝專案依賴。也可用：

```powershell
python server.py
```

開啟 <http://localhost:3000>。直接開啟 `index.html` 時會進入離線備援，但建議使用伺服器。

如需 AI 對話：

1. 在 [OpenAI API 平台](https://platform.openai.com/api-keys) 建立 API 金鑰，確認 API 專案可用。
2. 在專案資料夾執行 `copy .env.example .env`，用記事本開啟 `.env`，把 `OPENAI_API_KEY=` 後面填入金鑰。不要加空格或把金鑰貼到網頁對話框。
3. 關閉正在執行的遊戲視窗，重新執行 `start-game.cmd`。頁面頂端顯示「AI」表示已載入金鑰；與 NPC 對話才會發送請求。若顯示「離線備援」，代表沒有金鑰或請求失敗。

可用 `OPENAI_MODEL`、`PORT` 調整模型與埠號。`.env` 已加入 `.gitignore`。API 使用與 ChatGPT 訂閱分開計費。

## 操作

- 在小鎮用 WASD／方向鍵長按移動，E 與附近地標或居民互動。進入建築後，人物和物件以小圖示顯示在場景插畫上；點圖示或按其數字互動，無需移動。對話只覆蓋場景插畫區域，Esc 關閉。
- 點 NPC 後可按建議對話句，也可以在輸入欄自由輸入，Enter 送出。人物回應後，選項與輸入框會隱藏；按 Esc 離開，再次互動可展開新的對話。每位居民有「關心近況」「一起完成一件具體的事」「談記憶或未來」等選項；選擇會立即給出情境結果並更新信任、體力、居民記憶、三好四給與善意連結。意思相符的自由文字走相同的離線判定；其他文字仍會回覆，但離線模式無法理解所有說法。詢問子寧、雨柔或許浩的過去，可在對方同意後探索記憶。
- 在咖啡館製作咖啡獲得 18 元，花 12 元補充三份原料。時間、體力、金錢與進度會自動存入瀏覽器。
- 「結束今天」推進七日故事；第七天按下後顯示結局。結局可用原位置的「查看結局」按鈕再次開啟，也可重新遊玩。

## 測試三好四給與善意網路

- **雨天借傘**：進入咖啡館，點場景中的同名標記。選「借出自己的傘」會亮起「做好事」「給人方便」。與許浩再次對話，他會提到這件事。按「結束今天」後回咖啡館，事件標記變成後續事件 **雨後的回信**。原本的「雨天借傘」不會再出現。
- **剩食分享**：進入麵包店，點同名標記。選「幫她把麵包送給需要的居民」會亮起「做好事」「給人歡喜」。隔天麵包店會出現 **鄰里的餐桌**。也可以測試學校的 **考卷上的紅字**、公園的 **不能坐的長椅**、雜貨店的 **街角的爭執**；各有隔天的後續事件。
- 每個場景每天最多處理一件事件，且事件的相關 NPC 必須在場。完成主事件與後續事件後，該場景會隨機提供其他生活事件。30 種生活情境都有選項，完成後不會再次出現；每種也有隔天才解鎖的「○○的後續」。右側「居民記憶」會顯示他們記得的最新事件。
- 善意選擇會立即在網路中建立「你 → 受助者」連結。事件有約 75% 的進展機率；有進展時，居民可能再把幫助傳給別人。結果不順利仍會記住你的嘗試。選擇不介入不會亮燈或建立連結，也不會被當成道德懲罰。

## 測試結局

正常遊玩時，按「結束今天」直到第七天結束，就會看到依存檔判定的結局；之後按「查看結局」可重看。主結局共有 13 類，判定依照善意次數、居民自主互助、後續事件、咖啡營業、記憶線索和認識的居民。結局會列出存檔裡實際發生的選擇、受助居民的改變，以及有來源事件 ID 的後續傳播；已經歷的角色故事另有對應尾聲。不同選擇可能得到同一主結局，但影響回顧會不同。

若要快速檢查結局畫面，開啟 `http://localhost:3000/?test=1`，右側會出現「結局測試預覽」。選任一結局後按預覽，可查看以模擬條件產生的文字；**預覽不修改存檔**。要確認自己真正達成的結局，仍須完成七天。

## 結構

- `game.js`：移動、場景、互動、經營、存檔、事件與善意傳播。
- `src/world.js`：30 種場景事件與三條記憶線。
- `src/story.js`：主事件、後續事件、NPC 記憶、離線對話提示與事件狀態驗證。
- `src/npc-actions.js`：六位 NPC 的可選互動、自由文字對應與離線結果。
- `src/endings.js`：13 類主結局、個別角色尾聲與不改存檔的預覽條件。
- `src/dialogue.js`：AI 提示、輸入驗證、離線備援。
- `server.py`：Windows 預設啟動的靜態檔與對話 API；`server.js` 是 Node.js 替代版本。API 金鑰只在後端進程使用。
- `assets/`：動漫場景與人物圖片，與程式碼分開。

小鎮地圖 `assets/town-rpg.png` 依使用者提供的傳統 RPG 像素風格參考，以內建 ImageGen 產生；室內場景維持原有插畫。居民每天有全鎮唯一的出現地點，咖啡館有兩位，其他場所最多一位。

## 目前限制

場景使用圖片與 DOM 定位，碰撞仍是建築與水域的近似區塊，尚無逐格角色動畫。生活事件都可選擇，但 30 種情境中的一般事件使用共通的三種處理方式，後續文字也採共通模板；五條主要事件有專屬對話。NPC 會記住事件與最近幾次對話，但尚無完整的人際關係模擬。記憶世界仍使用共用背景。離線自由文字靠規則辨識，無法像 LLM 一樣理解任意做法；即使日後設定 LLM，資源與事件結果仍由程式驗證。GitHub Pages 只能提供離線備援，AI 需要能執行後端的主機。
