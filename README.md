# 微光咖啡館 LUMINA CAFÉ

七天的小鎮生活模擬 RPG。以俯視像素地圖探索街道，進入咖啡館、學校、麵包店、雜貨店、公園與三位居民的人生記憶；經營咖啡館、自由對話，觀察善意如何在居民間流動。

## 啟動

Windows 可直接雙擊 `start-game.cmd`，或在專案資料夾的命令提示字元輸入：

```cmd
start-game.cmd
```

啟動器會尋找 Python 3.10+（`py -3`，再試 `python`），找不到或版本不足才改用 Node.js 20+。無需安裝專案依賴。實際網址以伺服器輸出為準。也可手動執行：

```powershell
py -3 server.py
npm start
```

預設開啟 <http://localhost:3000>。直接開啟 `index.html` 時會進入離線備援，但建議使用伺服器。

伺服器預設只監聽 `127.0.0.1`，避免在區域網路暴露付費 API。可用 `.env` 的 `HOST` 與 `PORT` 調整；`PORT=0` 會使用隨機可用埠，並由伺服器印出實際網址。`/api/dialogue` 有每 IP 每分鐘 20 次、同時最多 4 項請求的限制，超過會回 429／503。若需要跨來源呼叫，請明確設定 `ALLOWED_ORIGIN`，不會使用 `*`。

如需 AI 對話：

1. 在 [OpenAI API 平台](https://platform.openai.com/api-keys) 建立**專案範圍**金鑰，設定用量上限並定期輪替，確認 API 專案可用。
2. 在專案資料夾執行 `copy .env.example .env`，用記事本開啟 `.env`，把 `OPENAI_API_KEY=` 後面填入金鑰。不要加空格、不要貼到網頁對話框、不要把 `.env` 上傳。
3. 關閉正在執行的遊戲視窗，重新執行 `start-game.cmd`。頁面頂端顯示「AI」表示已載入金鑰；與 NPC 對話才會發送請求。若顯示「離線備援」，代表沒有金鑰、請求失敗或已達限流。

可用 `OPENAI_MODEL`、`PORT`、`HOST`、`ALLOWED_ORIGIN` 調整模型、監聽位置與來源政策。`.env` 已加入 `.gitignore`。API 使用與 ChatGPT 訂閱分開計費。

## 操作

- 主選單的「進入遊戲」會載入目前存檔，「遊玩說明」可查看操作。進入遊戲後，左上角小地圖下方的任務欄預設只顯示主線的下一步。點任務提示可展開七日進度、體力和善意傳播網路。小鎮鏡頭會跟著角色移動，走到鄰近街區才會看到其他建築。點右上角「背包」或按 B 可查看目前的金錢與咖啡原料。再按 B 或 Esc 可關閉背包。左上角小地圖顯示附近街區與玩家位置，點小地圖或按 M 可開關小鎮全地圖。
- 在小鎮用 WASD／方向鍵長按移動，E 與附近地標或居民互動。進入建築後，人物和物件以小圖示顯示在場景插畫上；點圖示或按其數字互動，無需移動。對話只覆蓋場景插畫區域，Esc 關閉。
- 點 NPC 後可按建議對話句，也可以在輸入欄自由輸入，Enter 送出。人物回應後，選項與輸入框會隱藏；按 Esc 離開，再次互動可展開新的對話。每位居民有「關心近況」「一起完成一件具體的事」「談記憶或未來」等選項；選擇會立即給出情境結果並更新信任、體力、居民記憶、三好四給與善意連結。意思相符的自由文字走相同的離線判定；其他文字仍會回覆，但離線模式無法理解所有說法。詢問子寧、雨柔或許浩的過去，可在對方同意後探索記憶。
- 真正產生互動（幫忙、回應或探索記憶）後，居民才會被記為「熟悉的名字」；只點開頭像不算。
- 在咖啡館製作咖啡獲得 18 元，花 12 元補充三份原料。時間、體力、金錢與進度會自動存入瀏覽器；隨機結果使用存檔中的種子，因此同一存檔配合相同操作可重現。
- 「結束今天」推進七日故事；第七天按下後顯示結局且鎖定 gameplay 狀態，只能重看結局或重新遊玩。結局可用原位置的「查看結局」按鈕再次開啟。

## 測試三好四給與善意網路

- **雨天借傘**：進入咖啡館，點場景中的同名標記。選「借出自己的傘」會記錄「做好事」「給人方便」。與許浩再次對話，他會提到這件事。按「結束今天」後回咖啡館，事件標記變成後續事件 **雨後的回信**。原本的「雨天借傘」不會再出現。
- **剩食分享**：進入麵包店，點同名標記。選「幫她把麵包送給需要的居民」會記錄「做好事」「給人歡喜」。隔天麵包店會出現 **鄰里的餐桌**。也可以測試學校的 **考卷上的紅字**、公園的 **不能坐的長椅**、雜貨店的 **街角的爭執**；各有隔天的後續事件。
- 每個場景每天最多處理一件主線／生活事件，且挑選事件時就會確認相關 NPC 當天在場；若不在場，該場景會改挑其他可用事件，不會空耗額度。與居民一起完成的腳本行動另計，不會排擠主線事件。周奶奶每天固定在小鎮，因此小鎮不會出現無人的一天。
- 完成主事件與後續事件後，該場景會隨機提供其他生活事件。29 種通用生活情境都有選項，完成後不會再次出現；每種也有隔天才解鎖的「○○的後續」。居民會記住最近的事件，後續對話也可能提起它。
- 善意選擇會立即在網路中建立「你 → 受助者」連結。事件有約 75% 的進展機率；有進展時，居民可能再把幫助傳給別人。結果不順利仍會記住你的嘗試。選擇不介入不會記錄三好四給或建立連結，也不會被當成道德懲罰。腳本選項與意思相符的自由文字共用同一套判定，同一位居民一週只計一次善意。

## 測試結局

正常遊玩時，按「結束今天」直到第七天結束，就會看到依存檔判定的結局；之後按「查看結局」可重看。主結局共有 13 類，判定依照善意次數、居民自主互助、**成功的**後續事件、咖啡營業、記憶線索和真正互動過的居民。結局會列出存檔裡實際發生的選擇、受助居民的改變，以及有來源事件 ID 的後續傳播；五條主要事件的後續會優先進入回顧。不同選擇可能得到同一主結局，但影響回顧會不同。

若要快速檢查結局畫面，開啟 `http://localhost:3000/?test=1`，進入遊戲後展開小地圖下方的任務欄，即可找到「結局測試預覽」。選任一結局後按預覽，可查看以模擬條件產生的文字；**預覽不修改存檔**。要確認自己真正達成的結局，仍須完成七天。

## 結構

- `game.js`：移動、場景、互動、經營、存檔驗證、種子隨機、事件與善意傳播。
- `src/tilemap.js`：48×27 格小鎮地圖、地面與建築繪製、格子碰撞、人物方向與走路影格。道路、水域、樹木及建築佔地由同一份地圖資料定義；角色仍以百分比座標存檔以相容舊進度。
- `src/world.js`：29 種通用生活情境與三條記憶線。
- `src/story.js`：主事件、後續事件、NPC 記憶、離線對話提示與事件狀態驗證。
- `src/npc-actions.js`：六位 NPC 的可選互動、自由文字對應與離線結果。
- `src/endings.js`：13 類主結局、個別角色尾聲與不改存檔的預覽條件。
- `src/dialogue.js`：AI 提示、輸入驗證、離線備援。
- `src/offline.js`：瀏覽器與伺服器共用的離線 intent 判定。
- `src/diagnostics.js`：前端錯誤顯示。
- `server.py`：Windows 預設啟動的靜態檔與對話 API；`server.js` 是 Node.js 替代版本。API 金鑰只在後端進程使用，兩邊都有 loopback 預設、方法白名單、符號連結檢查與限流。
- `assets/`：動漫場景與人物圖片。`town-rpg.png` 是舊版小鎮地圖素材；`town.png`／`cafe.png` 是插畫背景，`places.png` 是室內合圖，`characters.png` 是角色 sprite 圖集，`player.png` 是玩家素材。

小鎮由 Canvas 根據格子資料即時繪製，不再使用 `assets/town-rpg.png` 作背景；道路邊緣、水岸、橋、建築立面、街燈與公園細節也由程式繪製。咖啡館是平屋頂街邊店面，有杯子招牌與落地窗；學校是對稱雙層校舍，有鐘樓與入口柱；麵包店是斜屋頂小屋，有煙囪與麵包展示窗；雜貨店是低矮市場店鋪，有遮棚與蔬果展示。室內場景維持原有插畫。

小鎮地圖 `assets/town-rpg.png` 依使用者提供的傳統 RPG 像素風格參考，以內建 ImageGen 產生；室內場景維持原有插畫。居民每天有全鎮唯一的出現地點，咖啡館有兩位，其他場所最多一位。

## 測試

```powershell
npm test
py -3 -m py_compile server.py
```

`npm test` 使用 Node 內建 test runner，會執行 `tests/*.test.js`，包含遊戲邏輯與兩套伺服器的 HTTP contract。

## 目前限制

小鎮使用格子碰撞與程式繪製的人物走路影格；室內仍使用圖片與 DOM 標記，無室內自由行走。生活事件都可選擇，但 29 種通用情境使用共通的三種處理方式，後續文字也採共通模板；五條主要事件有專屬對話。NPC 會記住事件與最近幾次對話，但尚無完整的人際關係模擬。記憶世界仍使用共用背景。離線自由文字靠規則辨識，無法像 LLM 一樣理解任意做法；即使日後設定 LLM，資源與事件結果仍由程式驗證。GitHub Pages 只能提供離線備援，AI 需要能執行後端的主機。
